# ROCm-specific dependencies for the RAG application
#
# ROCm 10.1.0 installed via pip (Windows 11, AMD Radeon RX 7900 XT, gfx1100).
# Install these FIRST, into a fresh Python 3.12 virtual environment:
#
#   python -m pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ "rocm[libraries,device-gfx1100]==10.1.0"
#   python -m pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ ^
#       "torch[device-gfx1100]==2.14.0+rocm10.1.0" ^
#       "torchvision[device-gfx1100]==0.29.0a0+rocm10.1.0" ^
#       "torchaudio==2.11.0.3+rocm10.1.0"
#
# Source (install selector, pip on Windows):
#   https://rocm.docs.amd.com/en/latest/install/rocm.html?fam=radeon&w=compute&gpu=amd-radeon-rx-7900-xt&os=windows&windows-ver=11&i=pip&gfx=gfx1100
#
# Notes:
# - Uninstall HIP SDK / older ROCm 7.x first, disable Smart App Control &
#   Windows Defender Application Guard, and keep the Adrenalin driver current.
# - Verify with:  python -c "import torch; print(torch.cuda.is_available())"  -> True
#   (and optionally:  hipinfo /  rocm-sdk targets)
# - Everything below this block assumes the ROCm PyTorch stack above is already
#   present in the environment; do NOT install plain "torch" from PyPI on top.
